# Theki Productions — Coming Soon

> **Official Waitlist & Direct WhatsApp Booking Experience for Theki Productions.**

Based on the dark Framer glassmorphism reference:
- **Glassified "THEKI" Background**: Giant bold capital **THEKI** typography rendered with frosted glass refraction, gradient highlights, and mouse-reactive 3D parallax powered by **GSAP**.
- **Reference Layout with "Book Now"**: Sleek single-row input pill on the left with the glowing white **"Book Now"** button on the right.
- **WhatsApp Direct Booking**: Submitting opens WhatsApp directly with **`+977 9769407270`** (`https://wa.me/9779769407270?text=...`).
- **Interactive Animations**:
  - **Mo.js**: Explosive, multi-color particle burst and expanding shockwave ring when clicking **"Book Now"**.
  - **GSAP**: Magnetic button physics, smooth entrance timeline, and fluid mouse parallax on the glassified background typography.
- **Minimalist Aesthetic**: Email form and social media icons removed for a clean, distraction-free glassified presentation.
- **Audio Experience**: Generative ambient drone and chord chime synthesized via the Web Audio API.
