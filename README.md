# Theki Productions — Coming Soon

> **Official Waitlist & Direct WhatsApp Booking Experience for Theki Productions.**

Based on the dark Framer glassmorphism aesthetic:
- **Glassified "THEKI" Background**: Giant bold capital **THEKI** typography rendered with frosted glass refraction, gradient highlights, and mouse-reactive 3D parallax powered by **GSAP**.
- **WhatsApp Direct Booking**: Replaced the telephone call link with direct **WhatsApp connection** (`+977 9769407270`).
- **Pre-filled Message Suite**: Select project types (Commercial, Photography, Music Video, Custom) or edit a custom message sent directly to WhatsApp.
- **Mo.js & GSAP Animations**:
  - **Mo.js**: Explosive, multi-color particle burst and expanding shockwave ring when clicking "Book on WhatsApp".
  - **GSAP**: Magnetic button physics, smooth entrance timeline, and fluid mouse parallax on the glassified background typography.
- **Removed Forms & Icons**: The email form and social media icons (Facebook, Instagram, Twitter) have been completely removed for a sleek, laser-focused layout.
- **Audio Experience**: Generative ambient drone and chord chime synthesized via the Web Audio API.
